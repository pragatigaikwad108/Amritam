# Amritam (अमृतम्): demo build (Stage 1)
Run: `npm install` then `npm run dev` and open http://localhost:3000. Also: `npm run lint`, `npm test`, `npm run build && npm start`.
Needs internet on first run (Google Fonts via next/font). Replace `public/logo.png` with your logo.
Copy `.env.example` to `.env.local` (not needed yet; Supabase arrives in Stage 2). Never use a service_role key.
